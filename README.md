# Accsoon Mac App

An independent macOS monitor app for the **Accsoon CineEye Air** wireless video
transmitter, built because the official Accsoon Go app for Mac is unreliable.

Not affiliated with Accsoon. This repository contains only our own notes and code.

- Plan: [docs/PLAN.md](docs/PLAN.md)
- Protocol notes (in progress): `docs/protocol.md`
- Tools (fake transmitter, prototype client): `tools/`
- Packet captures from your own device: `captures/`
